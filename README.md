# 3D-Segmentation-Of-The-Hippocampus

[![Python](https://img.shields.io/badge/Python-3.9-blue.svg)](https://python.org)
[![PyTorch](https://img.shields.io/badge/PyTorch-2.0-red.svg)](https://pytorch.org)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

End-to-end пайплайн автоматической сегментации гиппокампа по трёхмерным T1-взвешенным МРТ головного мозга.  
Модель достигает **Dice Similarity Coefficient 0.871** и **HD95 1.62 мм**, что сопоставимо с опубликованными SOTA-результатами для данной задачи.  
Проект включает строгую валидацию, анализ ошибок и бутстрэп-оценку доверительных интервалов.

---

## 🧠 Задача

Гиппокамп — ключевая структура мозга, участвующая в памяти и пространственной навигации. Его точная сегментация необходима для диагностики и мониторинга нейродегенеративных заболеваний (болезнь Альцгеймера, эпилепсия). Ручная разметка трудоёмка и субъективна, поэтому автоматические методы крайне востребованы.

Цель проекта — разработать и валидировать модель, которая по сырому МРТ-объёму предсказывает бинарную маску гиппокампа, пригодную для клинического использования.

---

## 📊 Данные

Использован открытый датасет **Medical Segmentation Decathlon (MSD) Task04 — Hippocampus**:

- **260** трёхмерных T1-MRI (с разметкой)
- Формат: NIfTI (.nii.gz)
- Предобработка: приведение к единому спейсингу, нормализация интенсивности, обрезка по маске мозга



---

## 🏗️ Архитектура решения

- **Модель:** 3D U-Net с модификациями (остаточные блоки, инстанс-нормализация)
- **Функция потерь:** комбинация Dice Loss + Cross-Entropy (DiceCELoss)
- **Оптимизатор:** AdamW, косинусное расписание learning rate
- **Аугментации:** случайные повороты, масштабирование, эластичные деформации (Monai)
- **Валидация:** стратифицированная 5-фолд кросс-валидация, финальная модель обучена на всех фолдах
- **Инструменты:** PyTorch, MONAI, SimpleITK, NumPy, Matplotlib, Jupyter Notebook

## 📈 Основные результаты (на внутреннем тесте, n=52)

| Метрика | Значение | 95% ДИ (bootstrap) |
|--------|----------|---------------------|
| Dice Score | **0.871** | [0.848, 0.890] |
| HD95, мм | **1.62** | [1.45, 1.80] |
| IoU (3D-детекция) | **0.807** | [0.780, 0.832] |
| Lin's CCC (волюметрия) | **0.914** | [0.885, 0.937] |

- Точность классификации срезов (есть/нет гиппокамп) — **F1 > 0.96**
- Систематическое смещение объёма: +120 мм³ (в пределах клинической нормы 3000–4500 мм³)

## 🔬 Детальный анализ

- **Декомпозиция ошибок:** False Positives / False Negatives, confusion matrix на уровне вокселей
- **Калибровка уверенности:** корреляция Softmax-вероятности и корректности предсказания
- **Bootstrap-анализ:** 1000 ресемплов для доверительных интервалов всех метрик
- **Клиническая интерпретация:** сравнение с литературными нормами объёма, оценка применимости
